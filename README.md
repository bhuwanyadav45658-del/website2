# 100xSolution

An immersive 3D marketing website built with React, Three.js, and Tailwind CSS.
Designed for 100xSolution to explain AI Marketing with cinematic visuals.

## Tech Stack
- **Framework**: React (Vite)
- **3D**: Three.js, @react-three/fiber, @react-three/drei
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Language**: JavaScript (ES6+)

## Project Structure
- `src/components/sections/` - Main page sections (Hero, Benefits, etc.)
- `src/components/three/` - 3D scene components
- `src/App.jsx` - Main layout assembly

## Getting Started

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Run Development Server**
   ```bash
   npm run dev
   ```

3. **Build for Production**
   ```bash
   npm run build
   ```

## SEO & Customization
- Metadata is configured in `index.html`.
- Theme colors are in `tailwind.config.js`.
